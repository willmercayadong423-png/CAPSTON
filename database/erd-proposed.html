Final draft — locked-in decisions:
  1. ROLES lookup seeded 1=Student, 2=Registrar, 3=Admin; users.role varchar replaced by role_id FK.
  2. STUDENT_PROFILES (1:1) receives all five student-only columns: user_id (PK&FK), student_id, lrn, grade_level, school_year_last_attended — all removed from users.
  3. DOCUMENT_TYPES no longer orphan — new document_requests.document_type_id FK replaces the old free-text document_type column (duplicate removed; the name is always read via the join).
  4. Relationships: 3 → 7. Only SITE_SETTINGS stands alone (system config — intentional).
